## Decisions

1. **Native host app plus WidgetKit extension; no Python at runtime.** A widget can't depend on a local web server or a Python process. The host app contains a small Swift port of the *verified* client calls only: `user/login`, `swimming_pool`, `swimming_pool/{p}/blue`, `blue/{s}`, `lastMeasurements`, `measures`. No new endpoints were explored. SigV4 is implemented with CryptoKit and unit-tested against a signature generated by botocore (the signer the Python client uses).
2. **Shared code** (`Shared/`) is compiled into the app, the widget and the tests: snapshot schema, formatting, status logic, the snapshot store, and the API client. The widget uses only the snapshot and formatting parts; it never performs network calls.
3. **App Group** `<TEAM_ID>.com.askasen.PoolMonitor` (team-prefixed macOS form, no provisioning profile needed). The host writes `snapshot.json` atomically (versioned schema); the widget reads it in `timeline()`.
4. **Credentials** live in the host app's Keychain item (`com.askasen.PoolMonitor.credentials`). They never reach the snapshot, logs or the widget. AWS session credentials are memory-only.
5. **Refresh cadence:** the device measures about every 72 min. The host refreshes every 30 min while running, plus on launch and on demand. After a successful write it calls `WidgetCenter.reloadTimelines(ofKind:)`, throttled to once per 5 min. The widget timeline policy is `.after(30 min)`, so WidgetKit decides actual timing; nothing is promised.
6. **Background:** opt-in "Open at login" via `SMAppService.mainApp` (the app keeps running in the menu bar with no Dock icon). There's no daemon. With the app quit or the Mac asleep, the widget shows the last snapshot with its age.
7. **Thresholds:** the server supplies per-pool ideal ranges (`ok_min`/`ok_max` in `lastMeasurements`), which are used for normal/attention status. Without them, the status is neutral ("unknown"). No hard-coded thresholds and no dosing advice.
8. **History:** the last 24 h of `measures` points, for sparklines and deltas. The delta compares the latest reading with the nearest actual reading ~24 h earlier (±3 h). Gaps over 3 h break the sparkline line instead of being interpolated. With fewer than 4 points the sparkline is omitted.
9. **Units:** temperature °C, pH, ORP mV ("Sanitation"), conductivity µS/cm. Salinity is not shown and never substituted.
10. **Multiple pools:** the account has one pool, so the widget uses `StaticConfiguration` with the primary pool. Pool selection via App Intent is a documented follow-up.
11. **Deep links:** `poolmonitor://pool` and `poolmonitor://metric/<temperature|ph|orp|conductivity>` open the host app.
12. **Deployment target** macOS 14.0 (needed for `containerBackground`).
